## 07.07.2026

### New: Testimonials

Anyone with dashboard access can now submit a testimonial for their server directly from the dashboard. Approved testimonials may be featured on the SupportMail homepage.

- Submit a testimonial from the new **Testimonial** page in the dashboard - a server can only have one.
- Only the person who submitted it can edit or revoke it; everyone else sees a read-only view naming the submitter.
- Once approved, changes require contacting support.

See [Testimonials](/managing-support/testimonials) for details.
