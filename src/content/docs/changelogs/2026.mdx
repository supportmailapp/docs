## 09.07.2026

### New: Pausing Tickets

Staff can now pause bot activity in a single ticket with `/ticket pause`, and resume it with `/ticket unpause`. While paused, the bot ignores all messages in the ticket post - nothing is forwarded to the user.  
Messages _from_ the user still reach the channel.

<Aside type="tip">
  You can also use the prefix commands `-pause` and `-unpause` in the ticket
  channel to pause and unpause the ticket, respectively.
</Aside>

- New **Ask to Delete History on Unpause** setting under [Message Handling](/configuration/ticket-system-config#message-handling) - when enabled, unpausing prompts staff to bulk-delete the messages sent while the ticket was paused.

See [Pausing Tickets](/managing-support/handling-tickets#pausing-tickets) for details. **Off by default.**

### New: Delete Reported Message on Punish

When punishing a reported user (timeout, kick or ban) via a message report, the action modal now includes a checkbox to also delete the reported message.

## 07.07.2026

### New: Testimonials

Anyone with dashboard access can now submit a testimonial for their server directly from the dashboard. Approved testimonials may be featured on the SupportMail homepage.

- Submit a testimonial from the new **Testimonial** page in the dashboard - a server can only have one.
- Only the person who submitted it can edit or revoke it; everyone else sees a read-only view naming the submitter.
- Once approved, changes require contacting support.

See [Testimonials](/managing-support/testimonials) for details.

## 28.06.2026

### New: Support Schedule

You can now define **support hours** so tickets can only be opened when your team is available. Set a timezone offset and up to 3 time slots per day; outside those hours the bot tells users when to try again instead of opening a ticket.

See [Support Schedule](/configuration/support-schedule) for details. Configure it on the new **Schedule** page in the dashboard.

### Changed: Panel moved to the dashboard

Creating and editing your [Panel](/configuration/panel) now lives fully in the dashboard on the **Panel** page - build it, save it and send it to a channel from there. The old `/config panel` command has been removed.
